# Civic Lens

Civic Lens is a civic intelligence platform for reporting, mapping, prioritizing, and resolving urban issues.

## Tech Stack

- React + TypeScript
- TanStack Start + TanStack Router
- Vite
- Tailwind CSS
- Supabase / PostgreSQL
- Drizzle ORM
- Leaflet / React Leaflet

## Local Development

1. Install dependencies with `npm install` or `bun install`.
2. Copy `.env.example` to `.env` and provide your own Supabase/database credentials.
3. Start the development server with `npm run dev` or `bun run dev`.

## Production Build

```bash
npm run build
```

The application is designed to run independently with standard Vite/TanStack tooling and your own backend infrastructure.
